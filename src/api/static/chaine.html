1. Format du fichier attendu

Deux colonnes obligatoires : url et question. Un exemple à 3 lignes ci-dessous pour chaque format accepté.

📊 Fichier Excel (.xlsx)
urlquestion

https://yb-techs.eu/Les services proposés

2. Envoyer ton fichier

Chaque ligne sera traitée par le pipeline complet (Selenium → OCR → OmniParser), puis un rapport PDF récapitulatif te sera proposé au téléchargement.

Traitement en cours — peut prendre plusieurs minutes selon le nombre de cas…
